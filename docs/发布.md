# 发布

## 一、推之前改两处

1. `package.json` 里的三个占位：`repository` / `homepage` / `bugs`，把 `<you>` 换成你的 GitHub 用户名。
2. `README.md` 里 `60 秒` 那段安装命令中的 `<you>`。

## 二、上传

```bash
git init
git add .
git commit -m "feat: dsh-qq 0.2.1 — 把 QQ 接到 DSH（文字/图片/表情/语音）"
git branch -M main
git remote add origin https://github.com/<you>/dsh-qq.git
git push -u origin main
```

打 tag（可选，但别人引用版本方便）：

```bash
git tag v0.2.1 && git push origin v0.2.1
```

## 三、仓库页面上要填的字

**About**（右上角齿轮里）：

```
把 QQ（NapCat/OneBot11）接到 DeepSeek Harness：文字、图片、表情、语音
```

**Topics**（About 右侧）：

```
deepseek-harness  dsh-plugin  dsh  qq  napcat  onebot11  onebot  bridge  im
```

Topics 决定别人能不能搜到你——只发仓库不填 Topics，基本等于不存在。

## 四、要不要进插件市场

DSH 的市场是另一套索引，格式要求写在 `dsh-plugin-market-index` 里：

| 要求 | 说明 |
|---|---|
| 索引 JSON `format: 1` | 不写或写错直接报 `$.format must be 1` |
| 每条要有 npm 包名 | 例如 `dsh-qq`，不是仓库 URL |
| 精确 SemVer | `0.2.1` 可以，`^0.2.1` / `0.2.x` 不行 |
| 40 位 commit | 完整 hash，缩写不行 |

所以进市场两条路：发到 npm（最省事），或者自己维护一份 index.json 并把 commit 写进去。
**只发 GitHub 仓库、不进索引，市场里搜不到**，但别人可以用 `dsh plugin add <git url>` 装。
